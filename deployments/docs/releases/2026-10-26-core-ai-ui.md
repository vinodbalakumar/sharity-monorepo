# Core, UI and Mac AI release ? 2026-10-26

Deployment target: existing `sharity-local` Docker stack serving the public site through the existing tunnel. All core services, AI, storefront and admin were rebuilt/redeployed; Tesla and live payments remain disabled. This is a feature-branch release, not a merge to the default branches.

## Delivered behavior

- Controlled public listing-image delivery fixes inaccessible storage URLs without exposing private assets. Public listing details reject unpublished drafts.
- Storefront cards, responsive categories, fonts, currency display, order ownership and real order-issue submission were repaired. Admin pages handle partial/downstream failures consistently.
- Environment profiles, Dockerfiles, Nginx configuration and active private TLS configuration are centralized in the deployments checkout. Generic application code/defaults remain in component repositories.
- AI uses the external Mac `qwen3:8b` profile with the requested 8192 context, 1024 output limit, temperature 0.3, disabled thinking and ten-minute keep-alive. There are no GPU overrides or automatic model downloads.
- Approved founder facts and live public product facts are retrieved for chat. Provider-specific HTTP transports now honor bounded connect/read limits independently of HTTP-client auto-selection.

## Remaining limits

The Mac API is still unreachable from this Windows/Docker host. Generated answer quality, GPU use and concurrent inference on the Mac are not certified; the provider outage is reported explicitly. See [Mac configuration and connectivity notes](../MAC_OLLAMA.md).

Existing Expo/npm security findings, credential-rotation work, prototype business screens, live payment/provider reconciliation and installed-device OAuth validation remain production-release gates. No clean vulnerability-scan or complete production-marketplace certification is claimed.
